Before we start

Useful questions, answered plainly.

If the work sounds familiar, send the current product or idea. We’ll help you find the next sensible move.

Do you only work with Bitcoin?

No. We work across Bitcoin, payments, DeFi and broader Web3 products when the product challenge is a good fit.

Can you improve an existing dApp or wallet interface?

Yes. We can audit the flow, improve the interaction model and build the changes alongside your protocol or backend team.

Do you provide smart-contract audits?

No. We focus on product design, application development and the experience around technical systems. Smart-contract security should be handled by a specialist auditor.
