# Public project feedback campaign

**Status:** ready for manual posting  
**Purpose:** collect useful product feedback through social replies while showing real Flat 18 work.

These posts ask about the product experience rather than asking people to rate Flat 18. Replies should be recorded by project and feature. Ask separately before turning any reply into a public testimonial.

## Posting guidance

- Use the supplied image with the post.
- Post to LinkedIn and X, then reply from the same account with the live product link and the case-study link.
- Keep the first question specific enough that someone can answer in one sentence.
- Reply to useful comments with a follow-up question: “What would you expect to happen there?”
- Do not describe a public build as a client result unless the client has approved that claim.
- For F18 Pay, use test data only. Never ask people to share wallet addresses, private keys, passwords or real payment details.
